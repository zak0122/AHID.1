# ChatGPT Research Worklog

This folder records substantive research work completed with ChatGPT for AHID. It is separate from the automated GitHub Actions discovery archive in `outcomes/`.

## Structure

- `YYYY/MM/YYYY-MM-DD.md`: dated record of ChatGPT research, verification, decisions and next actions.
- `YYYY/MM/MONTHLY_SUMMARY.md`: month-level overview and project progress.
- `templates/DAILY_TEMPLATE.md`: reusable daily entry template.

## Recording rules

1. Record only work actually completed in the relevant conversation/session.
2. Distinguish verified facts from preliminary interpretation and unverified leads.
3. Include source links/DOI/PMID where checked; never invent missing identifiers.
4. Record topic decisions as **Shortlisted**, **Promising—needs verification**, **Hold**, or **Rejected**, with reasons.
5. Do not call a topic publication-ready merely because a screening score is high.
6. Update the monthly summary when a meaningful daily entry is added.

ChatGPT cannot silently write to this repository in the background. A dated entry is added when ChatGPT performs the work and has repository-write access in that session. Conversation work not committed here should not be assumed archived.
